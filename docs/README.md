# 📚 Dokumentacja Habits Tracker

Pełna dokumentacja projektu **Habits Tracker** - aplikacji do śledzenia nawyków i monitorowania postępów.

## 🚀 O dokumentacji

Ta dokumentacja zawiera:

- **Wprowadzenie** - czym jest aplikacja i jakie są jej główne cechy
- **Główne funkcje** - opis wszystkich funkcjonalności
- **Architektura** - budowa projektu i struktura plików
- **Komponenty** - opis komponentów UI
- **Serwisy** - logika biznesowa aplikacji
- **Baza danych** - schemat i migracje
- **Szybki start** - jak uruchomić aplikację

## 📖 Jak czytać dokumentację?

### Lokalnie

1. Otwórz plik `index.html` w przeglądarce
2. Użyj menu boczne do nawigacji
3. Czytaj sekcje w dowolnej kolejności

### Online

Dokumentacja jest dostępna na stronie projektu (po wdrożeniu).

## 🎨 Design dokumentacji

Dokumentacja została stworzona z myślą o czytelności:

- **Ciemny motyw** - zmniejsza zmęczenie oczu
- **Zielone elementy** - nawiązanie do tematu zdrowia i nawyków
- **Responsywny design** - działa na wszystkich urządzeniach
- **Intuicyjna nawigacja** - łatwe poruszanie się po dokumentacji

## 📝 Struktura folderów

```
docs/
├── index.html       # Główny plik dokumentacji
├── styles.css       # Style CSS (ciemny motyw)
├── script.js        # JavaScript do interaktywności
└── README.md        # Ten plik
```

## 🛠️ Technologie użyte

- **HTML5** - struktura dokumentacji
- **CSS3** - styling z ciemnym motywem
- **JavaScript** - interaktywne elementy i nawigacja

## 🔄 Aktualizacja dokumentacji

Aby dodać nową sekcję:

1. Dodaj nowy `<section>` w `index.html`
2. Dodaj link w nawigacji `.sidebar-nav`
3. Zaktualizuj funkcję `showSection()` w `script.js` (jeśli potrzeba)

## 📱 Responsywność

Dokumentacja jest w pełni responsywna i dostosowuje się do:

- 📱 Telefonów (320px i więcej)
- 📱 Tabletów (768px i więcej)
- 🖥️ Desktopów (1024px i więcej)
