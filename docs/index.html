📖 Wprowadzenie

Habits Tracker to kompletna aplikacja webowa do monitorowania codziennych nawyków. Umożliwia tworzenie nawyków, śledzenie postępów w siatce dni oraz wizualizację danych za pomocą wykresów. Aplikacja jest zbudowana bez frameworków, używając nowoczesnego JavaScript ES6+.

Kluczowe cechy

  • Prosta instalacja: Brak autentyfikacji, dane przechowywane w Supabase
  • Responsywny design: Działa na urządzeniach mobilnych i desktop
  • Dostępność: Zgodna z WCAG AA
  • Udostępnianie: Generuj linki do publicznych widoków postępów

✨ Funkcjonalności

CRUD nawyków

Dodawanie, edycja i usuwanie nawyków z pełną walidacją.

Siatka dni z tracking

Widok tygodniowy z możliwością oznaczania wykonanych dni.

Persystencja danych

Automatyczny zapis w Supabase z obsługą błędów.

Wizualizacja

Wykresy słupkowe i kołowe pokazujące postęp.

Udostępnianie

Generowanie linków read-only z danymi w URL.

Licznik streaku

Śledzenie najdłuższej serii kolejnych dni.

Kategorie z kolorami

6 kategorii z dedykowanymi ikonami i kolorami.

Tryb ciemny/jasny

Automatyczne wykrywanie z przełącznikiem.

🏗️ Architektura

Struktura projektu

/
├── index.html # Główny plik HTML
├── src/
│ ├── main.js # Punkt wejścia aplikacji
│ ├── app.js # Główna logika aplikacji
│ ├── styles.css # Style CSS
│ ├── services/
│ │ ├── supabase.js # Serwis komunikacji z Supabase
│ │ ├── analytics.js # Serwis analityki
│ │ ├── share.js # Serwis udostępniania
│ │ └── theme.js # Serwis zarządzania motywem
│ └── components/
│ ├── HabitCard.js # Komponent karty nawyku
│ ├── HabitModal.js # Modal dodawania/edycji
│ ├── ShareModal.js # Modal udostępniania
│ └── Charts.js # Komponenty wykresów

└── package.json

Technologie

  • Frontend: Vanilla JavaScript (ES6+), HTML5, CSS3
  • Backend/Database: Supabase (PostgreSQL)
  • Wizualizacja: Chart.js 4.4.0
  • Build Tool: Vite 5.4
  • Czcionki: Inter (Google Fonts)

🚀 Instalacja i Uruchomienie

Wymagania

  • Node.js 18+
  • Konto Supabase (darmowe)

Kroki instalacji

  1. Klonuj repozytorium: git clone <repository-url>
  2. Zainstaluj zależności: npm install
  3. Skonfiguruj Supabase w pliku .env
  4. Uruchom aplikację: npm run dev
  5. Zbuduj produkcję: npm run build

🎯 Użytkowanie

Dodawanie nawyku

Kliknij "Add Habit", wypełnij formularz i zapisz.

Śledzenie postępu

Kliknij na dni tygodnia w karcie nawyku.

Udostępnianie

Użyj przycisku "Share" aby wygenerować link read-only.

📊 Struktura bazy danych

Tabela habits

- id (uuid, PK)
- name (text, 3-50 znaków)
- description (text, max 200 znaków)
- category (text)
- color (text, hex)
- icon (text, emoji)
- created_at (timestamptz)
- updated_at (timestamptz)

Tabela progress

- id (uuid, PK)
- habit_id (uuid, FK)
- date (date)
- done (boolean)
- created_at (timestamptz)
