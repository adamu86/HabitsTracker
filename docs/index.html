🎯 Habits Tracker

Dokumentacja aplikacji

Wprowadzenie

Witaj w dokumentacji Habits Tracker - zaawansowanej aplikacji webowej do śledzenia codziennych nawyków i monitorowania postępów w doskonaleniu się.

Czym jest Habits Tracker?

Habits Tracker to nowoczesna, responsywna aplikacja webowa zbudowana z najnowszymi technologiami (Vite, TypeScript, Tailwind CSS). Umożliwia użytkownikom:

  • ✅ Tworzenie i zarządzanie nawykami - dodawaj własne nawyki do śledzenia
  • 📊 Wizualizację postępów - wykresy i statystyki w czasie rzeczywistym
  • 📅 Śledzenie dzienne - zaznaczaj wykonane nawyki każdego dnia
  • 🔗 Udostępnianie wyników - podziel się swoimi postępami ze znajomymi
  • 📤 Eksport danych - pobieraj swoje dane do analizy
  • 🎨 Tryb ciemny/jasny - dostosuj interfejs do swoich preferencji
  • ⚡ Praca offline - aplikacja działa także bez internetu

Stack technologiczny

Frontend

Vite + JavaScript

Styling

Tailwind CSS + PostCSS

Backend & DB

Supabase (PostgreSQL)

Tools

ESLint, TypeScript

🚀 Cel projektu

Aplikacja ma na celu pomóc użytkownikom w budowaniu pozytywnych nawyków poprzez wizualizację postępów, śledzenie streków i motywowanie do ciągłości. Projekt łączy prostotę interfejsu z potężnymi funkcjami analitycznymi, pozwalając każdemu na monitorowanie i udoskonalanie swoich codziennych rutyn.

Główne funkcje

Poznaj bogatą funkcjonalność aplikacji Habits Tracker:

📝 Zarządzanie nawykami

Twórz, edytuj i usuwaj nawyki z łatwością. Każdy nawyk może mieć własny opis i kategorizację.

📊 Wizualizacja danych

Wykresy pokazujące postępy, streków i statystyki w zależności od czasu. Analizuj swoje dane w różnych przedziałach czasowych.

📅 Kalendarz interaktywny

Przeglądaj całą historię nawyków w formacie kalendarza. Szybko zobacz, które dni były produktywne.

🔗 Udostępnianie

Generuj shareable linki do swoich nawyków. Pokaż swoim przyjaciołom swoje postępy bez potrzeby tworzenia konta.

📤 Eksport danych

Pobieraj dane w różnych formatach (CSV, JSON) do dalszej analizy w Excel lub innym narzędziu.

🎨 Personalizacja

Tryb ciemny i jasny, dostosowywalne kolory i ustawienia interfejsu zgodnie ze swoimi preferencjami.

⚡ Offline First

Service Worker zapewnia pracę aplikacji offline. Dane są synchronizowane automatycznie po powrocie do sieci.

📱 Responsywny design

Aplikacja doskonale działa na wszystkich urządzeniach - od telefonów po desktopy.

Warstwy aplikacji

  • Warstwa UI: Komponenty React i HTML - odpowiadają za wyświetlanie interfejsu
  • Warstwa logiki: Klasa App zarządza stanem i przepływem danych
  • Warstwa serwisów: Serwisy obsługują komunikację z Supabase, export, share i inne funkcje
  • Warstwa danych: Supabase PostgreSQL przechowuje wszystkie dane użytkowników

Komponenty

Aplikacja zbudowana jest z następujących komponentów:

📋 HabitCard

Komponent wyświetlający pojedynczy nawyk na liście. Pokazuje aktualny stan, możliwość zaznaczenia jako wykonane, edycji i usunięcia.

➕ HabitModal

Okno modalne do tworzenia nowych nawyków i edycji istniejących. Obsługuje walidację formularza.

📅 CalendarModal

Interaktywny kalendarz umożliwiający przeglądanie i zarządzanie nawykami w widoku miesięcznym.

📊 Charts

Komponenty do wyświetlania wykresów i statystyk postępu nawyków.

🔗 ShareModal

Okno do generowania i kopiowania shareable linków do udostępniania nawyków innym osobom.

Serwisy

Aplikacja wykorzystuje kilka kluczowych serwisów obsługujących różne funkcjonalności:

🔌 supabase.js

Zarządza połączeniem z bazą danych Supabase. Obsługuje operacje CRUD dla nawyków i postępów.

📊 analytics.js

Oblicza statystyki i metryki nawyków. Analizuje streków, wskaźniki wykonania i trendy.

🔗 share.js

Generuje shareable linki z zakodowanymi danymi nawyków. Dekoduje dane z udostępnionych linków.

📤 export.js

Eksportuje dane nawyków do CSV i JSON. Umożliwia pobranie danych do analizy.

🎨 theme.js

Zarządza tematem aplikacji (dark/light). Zapisuje preferencje w localStorage.

Baza danych

Habits Tracker wykorzystuje PostgreSQL przez Supabase do przechowywania danych.

Schemat bazy danych

Aplikacja korzysta z następujących tabel:

  • habits - główna tabela przechowująca nawyki użytkowników
  • progress - śledzenie wykonania nawyków dzień po dniu
  • users - dane użytkowników (opcjonalnie)

Migracje

Migracja początkowa znajduje się w pliku 20251112153501_create_habits_tracker_schema.sql i tworzy całą strukturę bazy danych.

Szybki start

Zacznij korzystać z aplikacji w kilku prostych krokach:

1

Klonuj repozytorium

git clone https://github.com/yourusername/HabitsTracker.git
cd HabitsTracker
2

Zainstaluj zależności

npm install
3

Skonfiguruj Supabase

Utwórz plik .env.local z danymi do Supabase:

VITE_SUPABASE_URL=your_url
VITE_SUPABASE_ANON_KEY=your_key
4

Uruchom serwer deweloperski

npm run dev
5

Otwórz aplikację

Przejdź do http://localhost:5173 w przeglądarce.

📌 Przydatne komendy

  • npm run dev - uruchom aplikację w trybie deweloperskim
  • npm run build - zbuduj aplikację do produkcji
  • npm run lint - uruchom linter
  • npm run seed - załaduj dane testowe do bazy
